iPhone

安装小禾
版本 —

首次安装

  1. 用 Safari 打开本页，点“安装小禾”，弹窗里点“安装”，回到主屏幕等图标下载完。
  2. 点一次小禾图标，系统提示需要开发者模式，点“好”。
  3. 打开“设置 → 隐私与安全性 → 开发者模式”，开启后重启手机，重启后点“打开”。

装不上？

只有登记过 UDID 的 iPhone（iOS 16.4 及以上）能装。提示“无法安装”时，把手机 UDID 发给项目组登记。再打开本页点“安装小禾”即可覆盖更新。

安卓

下载安卓安装包
版本 —

首次安装

  1. 点“下载安卓安装包”，下载完成后打开 DailyAssistant.apk。
  2. 系统提示“禁止安装未知应用”时，按提示允许当前浏览器安装，再返回安装。
  3. 部分手机会提示“未经检测”或“风险应用”，选“继续安装”。

更新

再下载一次安装包直接安装即可覆盖更新，数据保留。
