# ITER1 原型 v7 · Stitch 提示词（web / mobile 子原型）

- 日期：2026-11-02
- 状态：草稿。对应共识 13.4 第 2 步；页面内容来自 `v7-子原型页面结构.md`（下称“页面结构”），编号 W-xx / M-xx 与之一致。
- 演示人物：p5 陆航（部门经理，第 30 天）为主；p1 苏晴只在注明处使用。姓名、数字为暂定虚构内容。

## 用法

1. Stitch 里建两个项目：**web 项目**（选 Web，桌面 1440 宽）、**mobile 项目**（选 App / Mobile，390×844）。
2. 每段提示词 = **§0 公共约束（必须整段贴在最前面）** + 端约束（§0.1 或 §0.2）+ 该页提示词。
3. **先做 4 个关键页定风格**：W-02 → M-02 → W-03a → M-06。风格满意后，在同一项目里接着出其余页面，并在提示词开头加一句“沿用本项目已有页面的风格和组件”。
4. 每页满意后：导出代码 + 截一张全页图，放进 `Stitch/v7/web/` 或 `Stitch/v7/mobile/`，文件名用页面编号（如 `W-02.png`、`W-02.html`），交给我整理界面规范、落成子原型。
5. 中间稿留在 `Stitch/`（不进 git）；定稿截图和界面规范放 `docs/ITER1/ui/`。

## 0. 公共约束（每段都贴）

```
这是中文产品“个人日常助手”（助手名叫“小禾”）的界面设计。产品定位：基于用户画像、主动替用户把事办好的私人管家，不是聊天客户端、不是待办工具、不是网盘。
本次演示用户是陆航，34 岁，互联网公司部门经理，带 6 人团队，向王总汇报，会议很多；产品帮他把“8 小时的汇报整理工作压到半小时”。
设计要求：
- 风格：朴素、干净、可信赖，像一位安静专业的私人秘书。不要渐变、发光、玻璃拟态、大面积插画、3D、emoji 堆砌。
- 用户 20–55 岁普通人，正文不小于 15px，行高宽松，按钮好点；信息层次清楚，一眼看出“做好了什么、要我决定什么”。
- 一种主色 + 中性灰；黄色只用于“🎯 因为…”依据条；红色只用于逾期 / 风险。领域用浅色小标签区分。
- 核心组件是“结果卡片”：领域标签、标题、交付深度标记、正文、每句后的小出处标签、“本次省下约 X 小时”、底部浅黄“🎯 因为…”依据条、“还可以帮你”两个次要选项、操作按钮、角落“这个别记”。
- 工作类内容只出草稿，不出现“发送”按钮；主按钮是“复制”或“用邮箱打开草稿”。
- 全部文案用简体中文，用下面给出的真实内容，不要用 Lorem ipsum 或英文占位。
- 不要引用外部图片和图标字体，图标用简单线性 SVG 或少量 emoji。
- 不要增加提示词里没有的功能和菜单。
```

### 0.1 web 端约束（web 项目每段加上）

```
桌面端 1440×900。左侧窄图标栏（可展开成带文字菜单），只有 5 个一级入口：管家、我盯着的事、交给我的资料、我了解的你、设置；右上角铃铛（通知中心）和用户头像。主内容区最大宽度约 1080px。
```

### 0.2 mobile 端约束（mobile 项目每段加上）

```
手机网页（H5），390×844，必须同时适用于 iPhone Safari 和 Android Chrome，两端外观和功能一致。
底部菜单栏 5 项：管家、盯着、资料、懂你、设置；顶部只有页面标题和铃铛。注意底部安全区。
不要画：从其他 App“分享到本产品”、震动、桌面角标、原生系统弹窗样式、iOS 或 Android 专属控件。收资料只用拍照、相册、录音、文件、粘贴链接、转发到专属邮箱。弹层一律用从底部弹出的面板。
```

```
设计通知中心（web 为右侧抽屉，mobile 为整页）。按时间倒序：“3 份下属周报已审完，2 处需要你看”（推送 · 16:02）、“团队周报已汇总”（推送 · 16:00）、“项目进度报告已更新”（安静 · 14:30）、“明早 9:00 提醒你跟进小李”（你让我提醒的 · 昨天）。每条：图标、一句话、时间、来源小标（推送 / 安静 / 你让我提醒的），未读加粗，可“全部已读”。
```

### M-09 吩咐一声（mobile 全屏输入）

```
设计全屏输入页：顶部关闭按钮；大输入框（提示“吩咐一声，比如：小周的周报哪里有问题？”）；下方建议说法小块；底部大号“按住说话”按钮和 📎。另出录音中状态：波形、计时 0:07、“松开发送，上滑取消”。
```

### W-09 后台通用列表页（web）

```
设计管理员后台“领域包”列表页：表格列出 8 个领域（工作事务标“首发主力”）、帮助数、触发规则数、评测样例数、状态；展开“工作事务”显示九类帮助 A 向上汇报、B 管理团队、C 会议、D 邮件、E 文档写作、F 项目跟进、G 个人节奏、H 工作资料查找、I 工作关系档案，各标“深做 / 中等 / 支撑”。风格比用户端更紧凑，但沿用同一套颜色和组件。
```
