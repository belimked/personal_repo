- 日期：2026-11-02
- 来源：整合 `v7-Stitch提示词.md` 与 `v7-子原型页面结构.md`，编号 M-xx 与之一致。
- 用法：
  1. Stitch 新建项目，选 **App / Mobile**（390×844）。
  2. **第 1 段是完整提示词**（含设计规范），必须最先贴，用它定风格。
  3. 第 1 段满意后，按顺序逐段贴其余提示词；每段都已带上“沿用风格”的开头，直接复制代码块内容即可。
  4. 第 2、3 段也是定风格的关键页，满意后再出其余页面。
  5. 每页定稿后导出代码 + 全页截图，放 `Stitch/v7/mobile/`，文件名用编号（如 `M-02.png`）。

## 第 1 段 · M-02 管家首页（完整提示词，先贴）

```
为中文产品“个人日常助手”设计手机 App 界面（用 H5 实现，iOS 和 Android 同一套设计），助手名叫“小禾”。产品定位：基于用户画像、主动替用户把事办好的私人管家，不是聊天客户端、不是待办工具、不是网盘。
演示用户：陆航，34 岁，互联网公司部门经理，带 6 人团队，向王总汇报，会议很多；产品帮他把“8 小时的汇报整理工作压到半小时”。

【设计规范，所有页面通用】
- 风格：朴素、干净、可信赖，像一位安静专业的私人秘书。不要渐变、发光、玻璃拟态、大面积插画、3D、emoji 堆砌。
- 用户 20–55 岁普通人：正文不小于 15px，行高宽松，点击区域不小于 44px；信息层次清楚，一眼看出“做好了什么、要我决定什么”。
- 颜色：一种主色 + 中性灰；黄色只用于“🎯 因为…”依据条；红色只用于逾期 / 风险。领域用浅色小标签区分（工作、孩子、家里、健康、钱、学习、人情、小店、出行）。
- 文案原则：只说出处，不说推断（写“因为上周例会纪要里提到…”，不写“我知道你…”“我猜你…”）；不出现“我记下了你…”之类的话；不向用户索要个人信息。
- 核心组件“结果卡片”：领域小标签、标题、交付深度标记（“一步到位”或“先给你个大概 · 展开看完整版”）、主动消息标记（“推送 · 原因”或“安静出现”）、正文、每句后的小出处标签、“本次省下约 X 小时”、底部浅黄“🎯 因为…”依据条（只写出处，右侧一个小“不对”按钮）、“还可以帮你”两个次要选项、操作按钮（复制 / 发给… / 改一改）、右上角小字“这个别记”。
- 工作类内容只出草稿，不出现“发送”按钮；主按钮是“复制”和“发给…”（打开手机邮件 App，收件人和正文已填好，用户自己发）。复制按钮旁一行很小的灰字“内容由 AI 生成”。
- 全部文案用简体中文和下面给出的真实内容，不要 Lorem ipsum 或英文占位。不引用外部图片和图标字体，图标用简单线性 SVG 或少量 emoji。不要增加提示词里没有的功能和菜单。

【App 框架】
手机屏幕 390×844，两端外观和功能一致，不要画 iOS 或 Android 专属控件。
底部菜单栏 4 项（线性图标 + 两字）：管家、盯着、资料、设置；顶部只有页面标题和右侧铃铛。注意顶部状态栏和底部安全区留白。
弹层一律用从底部弹出的面板（圆角顶部 + 拖拽条）。不要画读取微信聊天记录、通话录音、读短信等功能。收资料只用：从别的 App 分享过来、拍照、相册、录音、文件、粘贴链接、转发到专属邮箱。

【本页：“管家”首页，时间是周五下午 4 点，单列从上到下】
1) 问候“下午好，陆航”+ 一张小统计条“本周替你省下 11.5 小时”（数字突出），右侧小字“主动服务：开 ›”。
2) “需要你决定的（2）”：两张紧凑卡片，各两个按钮：
   - 💼 “小周的周报有 2 处和周三例会说的不一致，要我按会议结论整理修改意见吗？” 按钮：看修改意见 / 这周先不管
   - 📧 “客户方邮件问上线能否提前到 11 月 20 日，回复草稿已备好，三种口径任选。” 按钮：看草稿 / 稍后
3) “替你做好的（4）”：结果卡片纵向排列；卡片默认收起，只显示标签、标题、两行正文、“省下约 X 小时”、依据条和“展开”：
   - 💼 团队周报已汇总｜标记“推送 · 周五 18:00 前要交给王总”｜“6 份下属周报合成 1 页，先写结论：本周完成 3 项、延期 1 项（支付对接，卡在第三方证书）…”带小出处标签（邮件×6、例会纪要）｜省下约 3 小时｜依据条“🎯 因为前 3 次交给王总的周报都是一页、先写结论（出处：你发出的周报）”｜按钮：复制、发给…、展开
   - 💼 项目进度报告：会员系统 2.0｜“安静出现”｜“整体进度 72%，比计划慢 3 天；风险：支付对接连续两周延期（红色风险小标）”｜省下约 2 小时
   - 💼 和王总 1 对 1 的要点已整理成汇报｜“3 条决议、4 个行动项（2 条分给你）”｜出处“录音 12:40”“录音 27:15”
   - 📧 收件箱已分好｜三个数字块：要你回 3 / 要你知道 9 / 可以不看 24
4) “替你盯着的（5）”只显示 3 条 + “全部 ›”，每行：事项、管家在做什么、时间，例如“下周二 里程碑评审 · 已备好议程”“小李 3 天没回接口确认 · 明早 9:00 提醒你”。
5) 底部菜单栏上方悬浮一条“吩咐一声”输入条（点击进入全屏输入），右侧 🎤；旁边一个圆形 ＋ 按钮用于交资料。
重点：拇指可达，主要按钮在屏幕下半部分；卡片之间留白足够，不拥挤；可以画成长页面滚动。
```
