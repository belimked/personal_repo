- 用途：13.4 第 1 步。给 Stitch 提示词（`v7-Stitch提示词.md`）提供页面清单、跳转关系、每页区块和真实演示内容；之后做 `v7/web`、`v7/mobile` 两个子原型时按本文核对页面是否齐全。
- 规则编号：沿用 v6 功能说明的 `R-<模块>-<两位数>`。v7 新增的模块和编号（工作领域 A–I、邮箱、主动服务开关）在 v7 功能说明里定，本文先用占位写法 `R-工作-新`、`R-邮箱-新`、`R-主动-新`，功能说明定稿后统一替换。
- p5 的姓名、团队成员、项目名都是本文暂定的虚构演示内容，写 v7 设计文档时确认。

## 1. 总原则

1. **子原型只定界面**：功能、流程、规则以主原型_v7 和功能说明为准；子原型不放演示控制条、不做成长线、不做说明模式角标。
2. **演示数据**：默认人物 **p5 陆航 · 第 30 天**（工作领域是首发主力，最能体现界面密度）；另准备 **p1 苏晴 · 第 30 天** 一套，用于家庭类页面和对比（子原型右上角“切换演示人物”小入口，只在这两人之间切换）。
3. **导航固定**（R-界面-06，按共识 14.9 修订）：一级只有 4 项——🏠 管家、👀 我盯着的事、📂 交给我的资料、⚙️ 设置。待办、想做的事是二级页；“我了解的你”在 设置 › 隐私与个人信息 下。
4. **结果卡片是全产品最核心的组件**：两端用同一套信息结构（见 §2），只是排版不同。
5. **只出草稿不代发**（共识 14.5、14.10）：工作类卡片的主按钮是“复制”和“发给…”（默认打开手机邮件 App，收件人和正文已填好，用户自己点发送）；不出现“直接发送”。复制 / 导出旁有 AI 生成内容标识提示（共识 14.12，具体样式待法务确认）。
6. **移动端约束**（共识 14.13）：正式产品是原生 App，原型用网页在手机外框里演示，按 App 界面设计；只用 iOS 和 Android 原生 App 都支持的能力。收资料：**从别的 App 分享到这里 / 拍照 / 相册 / 录音 / 文件 / 粘贴链接 / 转发到专属收件邮箱**；通知用系统推送（首次需授权）+ 站内消息 + 邮件。不画：读取其他 App 数据（如微信聊天记录）、通话录音、读短信、长时间后台录音。权限第一次用到时才申请并说明用途。
7. 页面编号：web `W-xx`，mobile `M-xx`。同一功能两端编号尾数对应（W-02 ↔ M-02）。
8. **看破不说破**（共识 14.9）：所有文案只说出处，不说推断（“因为上周例会纪要里提到…”，不写“我知道你…”）；不出现“我记下了你…”这类提示；不主动问个人信息。
9. **“省下 X 小时”待定**（共识 14.14 第 7 条）：页面先保留，用户考虑后可能改为事实数字（如“6 份周报 → 1 页”）。
10. **第 1 天与空状态**（共识 14.14 第 6 条）：首页、我盯着的事、交给我的资料都要有第 1 天 / 空状态的样子。

## 2. 公共组件

| 组件 | 内容 | 规则 |
|---|---|---|
| **结果卡片** | 领域小标签（💼工作 / 🧳出行…）；标题；交付深度标记（“一步到位” 或 “先给你个大概 · 展开看完整版”）；主体内容；工作类带 **出处标签**（每句后小标签，点开看来源）和 **“本次省下约 X 小时”**；底部黄条“🎯 因为…”（只写出处，旁边一键“不对”，点开“哪里不对？说一句或打一句”）；“还可以帮你”2 个选项；操作：复制 / 发给… / 改一改（复制旁有 AI 标识提示）；角落“这个别记” | R-帮什么-03、R-帮什么-05、R-做多深-01、R-工作-03、R-工作-新 |

## 4. 每页区块与演示内容

### W-02 / M-02 管家首页（p5 第 30 天，周五 16:00）

区块从上到下（mobile 同顺序，单列）：
1. **问候行**：“下午好，陆航。本周替你省下 **11.5 小时**。”右侧主动服务状态小字“主动服务：开 ›”（R-主动-新）。
2. **需要你决定的（2）**：
   - “小周的周报有 2 处和周三例会说的不一致，要我按会议结论整理修改意见吗？”（B 管理团队）— 按钮“看修改意见” / “这周先不管”。
   - “客户方邮件问上线能否提前到 11 月 20 日，回复草稿已备好，三种口径任选。”（D 邮件）
3. **替你做好的（4 张结果卡片，横向/纵向排列）**：
   - 💼 **团队周报已汇总**（推送：周五 18:00 前要交给老板）——“6 份下属周报合成 1 页，先写结论：本周 3 项完成、1 项延期（支付对接，阻塞在第三方证书）、下周重点 2 项。”出处：6 封邮件 + 周三例会纪要。本次省下约 3 小时。因为：前 3 次交给王总的周报都是一页、先写结论（出处：你发出的周报）。还可以帮你：生成汇报 PPT 大纲 / 改成三行版。
   - 💼 **项目进度报告：会员系统 2.0**（安静出现）——“整体进度 72%，比计划慢 3 天；风险：支付对接连续两周延期。”省下约 2 小时。
   - 💼 **周三和王总 1 对 1 的要点已整理成汇报**——“3 条决议、4 个行动项（2 条分给你）”，出处：会议录音 12:40、27:15。
   - 📧 **收件箱已分好**：要你回 3 封 / 要你知道 9 封 / 可以不看 24 封。
4. **替你盯着的（5）**：一行一件，“下周二 会员系统 2.0 里程碑评审 · 已备好议程”“小李 3 天没回的接口确认邮件 · 明早提醒你跟进”等。
5. **吩咐一声** 输入条；建议说法：“把这周周报改成给王总的三行版”“小周的周报哪里有问题？”

p1 版首页：沿用 v6 第 30 天（秋假长沙一步到位、体检骨架、周报轻量版、47 天前的记账想法），用于对比同一页面在家庭类人物上的样子。

### W-03 / M-03 结果详情（三种工作类，各一个演示）

- **a 审下属报告**：左右两栏（mobile 改为上下 + 切换标签“原文 / 修改意见”）。左：小周的周报原文，问题句标黄；右：修改意见 2 条——“‘支付对接本周完成’与周三例会结论不符：会上定为下周三完成（出处：例会纪要第 3 条）”“漏了例会分给他的‘压测报告’”。底部：“复制修改意见” / “发给小周…” / “这条不算问题”（记为反馈）。省下约 40 分钟。
- **b 团队汇总给老板**：成稿 1 页，每句带出处标签；右侧（mobile 折叠）“用到的 6 份周报”列表，每份标“已审 / 有 2 处待确认”。按钮：复制 / 导出 .doc / 改成三行版。
- **c 按 1 对 1 会议写汇报**：上方会议信息（时长 38 分钟、录音、参会人），下方汇报稿；行动项表（事项、负责人、截止日期），“加入我盯着的事”。
- 共有：顶部面包屑“管家 › 团队周报”；“本次省下约 X 小时”；“🎯 因为…”；“这个别记”；依据条旁“不对”。用户改稿后不弹任何“我记下了”提示，下一稿直接按新改法写（看破不说破，共识 14.9）。

### W-04 / M-04 我盯着的事

- 顶部次级入口：“全部待办 ›”“想做的事 ›”。
- 按领域分组：p5 以 **💼 工作** 为主，并拆成小组：向上汇报 / 管理团队 / 会议 / 邮件跟进 / 项目；另有 🩺 健康（年度体检）、🎁 人情（同事婚礼随礼）。
- 每行：标题、管家正在做什么（“每周五 16:00 汇总团队周报”）、下一个时间点、领域标签。
- 空状态（只在说明里出现一次示意）：“你告诉我的事会在这里，我替你盯着”。

### W-05 / M-05 交给我的资料；W-05a / M-05a 搜索结果

- 标题“交给我的资料”；搜索框提示“说过的话、画面里的字、场景和人物都能搜”，示例：“上次谁说过预算砍 20%”。
- 交资料入口：web 为“上传 / 粘贴链接 / 转发到你的专属邮箱 luhang.7k2@in.xxx”；mobile 为右下 ＋ 打开 M-05b。
- 资料列表按类型分组（会议录音、邮件附件、文档、照片），每条：名称、时间、一句话摘要、标签。演示：`周三例会.m4a`（42 分钟）、`王总 1对1.m4a`、`会员系统2.0-需求说明.docx`、6 份下属周报（邮件）。
- 搜索结果：顶部“查询计划”标签（“最近一个月 · 会议 · 预算 · 20%”，可点掉）；结果按类型分组，定位到时刻（“周三例会 18:42 · 王总：预算先砍 20%”原话高亮）；“用时 1.2 秒”。
- p1 版：沿用 v6 的纳木错 / 新疆照片和 AI 泡沫视频样例。

### M-05b 交资料底部弹层（mobile）

六个大按钮：📷 拍照、🖼 相册、🎙 录音、📄 文件、🔗 粘贴链接、✉️ 转发到专属邮箱（显示地址 + “复制”）。下方一行：“拍一张会议白板，我替你整理；也可以在别的 App 里点‘分享’发给我”。首次上传前弹同意卡片；首次上传录音时提示“录音请征得参会人同意 · 知道了”（共识 14.5）。

### M-05c 分享到本产品（mobile）

用户在别的 App 里点系统“分享”选择小禾后出现：内容预览（文件名 / 链接标题 / 图片缩略图）、“交给我”主按钮、可选一句备注（“这是下周例会材料”）。

### W-06 / M-06 隐私与个人信息（设置下的二级页）

按共识 14.9 第 8 条，大白话呈现，不显示类型、标签、可信度：
1. **我了解的你**：一句一条，按领域分组；默认只列已印证的条目，底部“查看全部（含还没确认的）”（共识 14.14）。p5 演示：
   - 💼 工作：“你是部门经理，向王总汇报”“你每周五 18:00 前交团队周报”“你的稿子习惯短句、先说结论、数字放括号里”“给王总的汇报：先说结论，一页纸以内”。
   - 🩺 健康：“你每年 11 月做一次体检”。
   - 每条：一句话 + 小字来源（“来自：你改过的周报”“来自：周三例会纪要”）；两个按钮“不对”（点开说一句或打一句）、“删掉”。项目分工、团队成员不在这里。
   - 顶部一句：“这些是我为了把事办好而记下的。哪条不对，点一下告诉我。”
2. **敏感类别**：健康、财务、孩子、位置、人脸各一个开关。
3. **通用模式**：开关，说明“打开后不按你的情况定制，管家照样能用”。
4. **资料用途**：说明可以在任一资料上设置“只用来搜索”。
5. **导出全部数据**、**忘掉我**（红色文字按钮，二次确认）。

### W-07 / M-07 设置

分组：
1. **主动服务**（R-主动-新）：三档单选“开 / 只准备不通知 / 关”，说明一句“关了以后我只在你开口时做事；我了解你的部分照常更新；你让我提醒的事照常提醒”。下方“按领域设置”列表（工作 开、家里 只准备、健康 开…）；免打扰时段 22:00–07:30。
2. **工作邮箱**：已接入 `luhang@company.com`（Microsoft 365）· 只读取“收件箱 / 下属周报”两个文件夹 · 断开（断开后删除已读取内容）。

4. **通知**：站内消息（总开）、邮件提醒（每天 8:00 摘要）、系统推送（mobile：未开启 · “开启 ›”（进入 M-07b）→ M-07b）。
5. **隐私与个人信息 ›**（进入 W-06 / M-06）。

### W-07a / M-07a 接入工作邮箱

### M-07b 开启通知授权页

在第一次需要推送时出现（不在启动时弹）：说明“开启后，备好的结果和你让我提醒的事会及时通知你”；按钮“开启通知”（之后才出现系统授权弹窗）/“先不用”。拒绝后不再反复弹，消息仍在站内和邮件里提醒。

### W-00 / M-00 第 1 天首页
