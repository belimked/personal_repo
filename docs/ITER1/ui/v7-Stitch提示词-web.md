# ITER1 原型 v7 · Stitch 提示词 · Web 端（整合版）

- 日期：2026-11-02
- 来源：整合 `v7-Stitch提示词.md` 与 `v7-子原型页面结构.md`，编号 W-xx 与之一致。
- 用法：
  1. Stitch 新建项目，选 **Web**（桌面 1440 宽）。
  2. **第 1 段是完整提示词**（含设计规范），必须最先贴，用它定风格。
  3. 第 1 段满意后，按顺序逐段贴其余提示词；每段都已带上“沿用风格”的开头，直接复制代码块内容即可。
  4. 第 2、3 段也是定风格的关键页，满意后再出其余页面。
  5. 每页定稿后导出代码 + 全页截图，放 `Stitch/v7/web/`，文件名用编号（如 `W-02.png`）。

## 第 1 段 · W-02 管家首页（完整提示词，先贴）

```
为中文产品“个人日常助手”设计桌面端 Web 界面，助手名叫“小禾”。产品定位：基于用户画像、主动替用户把事办好的私人管家，不是聊天客户端、不是待办工具、不是网盘。
演示用户：陆航，34 岁，互联网公司部门经理，带 6 人团队，向王总汇报，会议很多；产品帮他把“8 小时的汇报整理工作压到半小时”。

【设计规范，所有页面通用】
- 风格：朴素、干净、可信赖，像一位安静专业的私人秘书。不要渐变、发光、玻璃拟态、大面积插画、3D、emoji 堆砌。
- 用户 20–55 岁普通人：正文不小于 15px，行高宽松，按钮好点；信息层次清楚，一眼看出“做好了什么、要我决定什么”。
- 颜色：一种主色 + 中性灰；黄色只用于“🎯 因为…”依据条；红色只用于逾期 / 风险。领域用浅色小标签区分（工作、孩子、家里、健康、钱、学习、人情、小店、出行）。
- 文案原则：只说出处，不说推断（写“因为上周例会纪要里提到…”，不写“我知道你…”“我猜你…”）；不出现“我记下了你…”之类的话；不向用户索要个人信息。
- 核心组件“结果卡片”：领域小标签、标题、交付深度标记（“一步到位”或“先给你个大概 · 展开看完整版”）、主动消息标记（“推送 · 原因”或“安静出现”）、正文、每句后的小出处标签、“本次省下约 X 小时”、底部浅黄“🎯 因为…”依据条（只写出处，右侧一个小“不对”按钮）、“还可以帮你”两个次要选项、操作按钮（复制 / 发给… / 改一改）、右上角小字“这个别记”。
- 工作类内容只出草稿，不出现“发送”按钮；主按钮是“复制”和“发给…”（打开邮件客户端，用户自己发）。复制按钮旁一行很小的灰字“内容由 AI 生成”。
- 全部文案用简体中文和下面给出的真实内容，不要 Lorem ipsum 或英文占位。不引用外部图片和图标字体，图标用简单线性 SVG 或少量 emoji。不要增加提示词里没有的功能和菜单。

【Web 框架】
桌面端 1440×900。左侧窄图标栏（可展开成带文字菜单），只有 4 个一级入口：管家、我盯着的事、交给我的资料、设置；右上角铃铛（通知中心）和用户头像。主内容区最大宽度约 1080px，居中。

【本页：“管家”首页，时间是周五下午 4 点】从上到下：
1) 问候行：“下午好，陆航。本周替你省下 11.5 小时”（数字突出）；右侧小字链接“主动服务：开 ›”。
2) “需要你决定的（2）”区块，两条横向卡片，各有主次两个按钮：
   - 💼 “小周的周报有 2 处和周三例会说的不一致，要我按会议结论整理修改意见吗？” 按钮：看修改意见 / 这周先不管
   - 📧 “客户方邮件问上线能否提前到 11 月 20 日，回复草稿已备好，三种口径任选。” 按钮：看草稿 / 稍后
3) “替你做好的（4）”区块，结果卡片两列网格：
   - 💼 团队周报已汇总｜标记“推送 · 周五 18:00 前要交给王总”｜正文“6 份下属周报合成 1 页，先写结论：本周完成 3 项、延期 1 项（支付对接，卡在第三方证书）、下周重点 2 项。”每句后有小出处标签（邮件×6、例会纪要）｜“本次省下约 3 小时”｜依据条“🎯 因为前 3 次交给王总的周报都是一页、先写结论（出处：你发出的周报）”｜还可以帮你：生成汇报 PPT 大纲 / 改成三行版｜按钮：复制、发给…、展开
   - 💼 项目进度报告：会员系统 2.0｜标记“安静出现”｜“整体进度 72%，比计划慢 3 天；风险：支付对接连续两周延期（红色风险小标）”｜省下约 2 小时
   - 💼 和王总 1 对 1 的要点已整理成汇报｜“3 条决议、4 个行动项（2 条分给你）”｜出处标签“录音 12:40”“录音 27:15”
   - 📧 收件箱已分好｜三个数字块：要你回 3 / 要你知道 9 / 可以不看 24
4) “替你盯着的（5）”紧凑列表，每行：领域标签、事项、管家正在做什么、下一个时间点，例如“下周二 会员系统 2.0 里程碑评审 · 已备好议程”“小李 3 天没回接口确认邮件 · 明早 9:00 提醒你跟进”。
5) 底部固定“吩咐一声”输入条（📎、输入框“吩咐一声，比如：把周报改成给王总的三行版”、🎤、发送），上方一行建议说法小块：“把这周周报改成给王总的三行版”“小周的周报哪里有问题？”。
重点：首屏能看到问候、需要你决定的、至少两张结果卡片；结果卡片各部分层次清楚，依据条醒目但不抢正文。
```

```
重点：原文高亮句和意见编号一一对应，一眼看清；出处浮层清楚显示来源类型和时间点。
```
