# 日历时长设置与拖拽界面调研

- 调研日期：2026-10-25
- 用途：原型 v2 的待办时长功能（快捷选项 + 时间轴拖拽）
- 核实标记：✅ 主代理打开原文核实；◐ 子代理引用官方原文，主代理未核实；⚠ 推断或查不到

## 各产品要点

| 产品 | 时长输入 | 时间轴拖拽 | 单击空白的默认时长 | 来源 |
|---|---|---|---|---|
| Todoist | 安排器里"持续时间"栏，可选择或输入；支持 `【1h15m】` 写法；上限 24 小时 | 拖动任务底部边缘设置时长；从全天栏拖入时间轴默认 15 分钟 | ✅ 30 分钟（"在日历中点击您喜欢的时间段……设置为30分钟的持续时间"） | https://www.todoist.com/help/todoist/features/set-a-task-duration-L1kYkZv8d |
| Google 日历 | 开始 + 结束时间，时长由两者推出 | ◐ 单击空白新建，按住向下拖动可加长；移动端拖动上下圆点改时长 | ◐ 可在设置中修改；管理员推荐 30 分钟 | https://support.google.com/calendar/answer/72143 、https://support.google.com/a/answer/9347087 |
| Google 日历（短事件） | — | ◐ 25 分钟及以下的事件按真实高度显示；中文、日文、韩文账户默认关闭此功能，以保证文字清晰 | — | https://workspaceupdates.googleblog.com/2020/07/better-visualize-shorter-meetings-in-calendar.html |
| Apple 日历 | 开始 + 结束 | ◐ 日/周视图中从开始拖到结束来新建；拖动顶部或底部边缘改开始或结束时间 | ◐ iOS 可设置"新日程时长" | https://support.apple.com/zh-cn/guide/calendar/icalwr13-events/11.0/mac/10.15 |
| Outlook | 开始 + 结束，默认按整点或半点对齐，可手动输入任意时间 | ◐ 时间刻度可改为 5/6/10/15/30/60 分钟 | ⚠ 未查到 | https://support.microsoft.com/zh-cn/outlook/create-or-schedule-an-appointment |
| 滴答清单 | ◐ 日期选择器切换到"Duration"，选开始和结束时间，可跨天 | ◐ 长按时间轴新建默认 1 小时；长按拖动可设任意时长；拖动块边缘调整时长 | ◐ 1 小时 | 子代理引用的帮助页现已 404，⚠ 未核实 |
| Fantastical | 开始 + 结束；可设置默认时长 | ◐ 拖动定时事件的上下边缘改开始或结束时间 | ◐ 可设置 | https://flexibits.com/fantastical/help/editing-events-and-tasks |

查不到的内容：各产品的吸附粒度、拖动时是否显示时间气泡、默认时长下拉的完整选项，官方文档均未写明。

## 原型 v2 采用的方案

| 设计 | 借鉴 | 说明 |
|---|---|---|
| 时长快捷选项：15 分钟、30 分钟、45 分钟、1 小时、2 小时 | 用户指定；Todoist 的"选择或输入" | 拖拽得到的非预设时长显示为"自定义 X" |
| 单击空白新建默认 30 分钟；按住拖动则以拖出的长度为准 | Todoist（30 分钟）、Google（拖选加长） | |
| 上下边缘都可拖：下边缘改时长，上边缘改开始时间 | Apple、Google、Fantastical | |
| 按 15 分钟吸附，拖动时块内实时显示"开始–结束 · 时长" | 吸附值为我们的决定（各产品未公开） | |
| 时间轴 1 像素 = 1 分钟；时长 ≤30 分钟的块只显示一行；最小高度 18 像素 | Google 短事件显示及中日韩例外 | |
| 不跨天，最晚到 24:00 | Todoist（不支持跨天定时任务，上限 24 小时） | |
| 每次修改都有提示，可撤销 | 沿用 v1 | |
