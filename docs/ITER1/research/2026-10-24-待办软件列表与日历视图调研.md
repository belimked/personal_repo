# 待办/任务软件「列表视图 + 日历视图」界面调研（2025–2026）

- 调研日期：2026-10-24
- 目的：为个人日常助手（待办字段：标题、日期、可选时间、地点、来源、附件、状态 未完成/已完成/已归档）设计「列表 + 日历」两种视图
- 方法：只用官方帮助中心 / 官方功能页，逐个产品直接打开原文（不依赖搜索摘要）；搜索仅用于定位 URL
- 核实标记：**✅** 我亲自打开官方原文并摘录；**⚠** 推断（原文未写明，来自产品常识/界面截图）；**✗** 查不到

> 一句话结论：五家产品的共同骨架是「**日期分组列表** + **全天区/时间轴两段式日历** + **未排期任务停靠区**」。差异主要在：日历模式数量（TickTick 最多）、切换方式（Todoist 是「每视图一个 layout」，TickTick 多一个「列表+日历并排」）、以及「没有独立日历」的产品（MS To Do、Things 3、Google Tasks）如何把日历借过来。

## 1. 滴答清单 TickTick

来源均为官方帮助中心 `help.ticktick.com`，下列「更新」取页面 JSON 里的 `modifiedTime`。

### 1.1 列表视图

- **分组**（✅）：智能清单固定为 All / Today / Tomorrow / Next 7 Days（"Smart lists: Lists that intelligently filter and display tasks based on certain conditions, such as All, Today, Tomorrow, and Next 7 Days."）— https://help.ticktick.com/articles/7055782422935240704 （2026-10-22）
- **分组枚举**（✅）：普通清单支持 Group & Sort，按时间分组时固定五档：**Today / Tomorrow / Next 7 days / Later / Overdue**；另可按清单、优先级（High/Medium/Low/No Priority）、标签、指派对象、创建时间分组。排序支持日期、优先级、创建时间、修改时间。
  原文："Tasks will be grouped into: Today, Tomorrow, Next 7 days, Later, Overdue" — https://help.ticktick.com/articles/7056594711640801280 （2026-10-10）
- **层级**（✅）：Folder – List – Section – Task – Subtask 五级 — https://help.ticktick.com/articles/7055782309420597248 （2026-10-10）
- **单行信息**（⚠）：复选框、标题、日期/时间（逾期日期标红）、优先级色块、标签、清单色点、子任务计数。官方文档只以截图呈现，未逐项文字说明 — https://help.ticktick.com/articles/7055782365863346176 （2026-10-18）
- **快速操作**（✅）：
  - 移动端左滑出现 Move / Delete / Modify Date，右滑 Done / Pin，可在设置里改这两个动作 — 同上
  - 桌面端悬停出拖拽把手，可拖到侧栏清单/智能清单/标签（"Drag a task onto a Smart List to auto-assign the corresponding due date"）— https://help.ticktick.com/articles/7351523697951244288 （2026-10-21）
  - 拖到另一任务右下角 → 变子任务（✅）
  - 右键菜单：Date / Move to / Tags / Priority（✅）— https://help.ticktick.com/articles/7055782408586526720 （2026-09-20）
  - Pin 置顶（✅）
- **批量**（✅）：桌面 Ctrl/Shift 点选、Shift+↑↓、框选；右侧批处理工具栏可改日期、优先级、清单、标签；`Ctrl+0` 设为今天。移动端「…」→ Select 或长按进入多选，可批量改期/换清单/删除/设优先级/合并 — https://help.ticktick.com/articles/7055782365863346176 、 https://help.ticktick.com/articles/7351523697951244288
- **筛选**（✅）：Filters 支持普通筛选（清单名、标签、日期、关键词）和高级筛选（AND/OR 多条件，可 Preview）— https://help.ticktick.com/articles/7055782003394646016 （2026-10-23，页面标题 Filters - Choose What You Want to See）

### 1.2 日历视图

- **模式**（✅）：
  - 周视图，移动端有「时间轴布局」和「8 宫格（8-block）布局」两种；桌面端只有时间轴 — https://help.ticktick.com/articles/7055782149730861056 （2026-08-21）
  - 月视图 — https://help.ticktick.com/articles/7055782128335716352 （2026-08-21）
  - 年视图（热力图，默认关闭；只显示有日期的任务）— https://help.ticktick.com/articles/7399726920725692416 （2026-08-21）
  - 议程 Agenda（桌面 6.0 起，"all your scheduled tasks are displayed in a linear timeline"，可同时看到过去已完成、当前、未来）— https://help.ticktick.com/articles/7213444784319365120 （2026-08-21）
  - 日视图 / 3 日视图：**仅移动端**（"we also provide 'Daily View' and '3-Day View' on mobile devices"）
  - 多日视图 / 多周视图：**仅桌面端**（"Note: Multi-Day View and Multi-Week View are available on desktop only"）
  - 「日历 List View」（官方标题 List View - View Tasks by Day）：按天罗列的议程式日历，可选 Show Timeline（"In the 'List View,' tasks are presented in the form of 'to-do items'"）— https://help.ticktick.com/articles/7055782110086299648 （2026-08-21）
- **全天 vs 定时**（✅）：周视图分「全天任务条」与「垂直时间轴」两段：
  > "All-day Task Bar: Tasks that are 'unassigned time' for the day, all-day tasks, and cross-day tasks will be displayed here."
  > "Vertical Timeline: Tasks with set times will be displayed directly on the timeline."
  全天条高度可拖拽调整（桌面），以便放下更多全天任务而不重叠（✅）。
- **任务太多时折叠**（✗）：官方文档没有写「+N 更多」的具体规则，也没找到月视图溢出策略的文字说明（见第 8 节）。
- **已完成显示**（✅）：View Options → **Show Completed** 开关；周视图里"completed tasks will appear lighter in color"（变淡，未提删除线）。
- **逾期标记**（⚠）：列表分组里有 Overdue 档；日历里逾期任务的红字/红块官方未文字说明。另有 Suggested Tasks 的「Long Overdue」分组（超 7 天/14 天…）— https://help.ticktick.com/articles/7401564165023727616 （2026-10-10）
- **拖拽**（✅）：拖任务块改时间；鼠标放到块边缘出现上下箭头后拖动改时长；月视图里长按起始日期格拖到结束日 → 建跨天任务；移动端网格布局里拖任务到屏幕边缘 → 换到下一周，拖到小日历上 → 直接改日期。
- **空白处新建**（✅）：点日期格 / 点时间轴（默认 1 小时）/ 长按拖动出任意时长；移动端长按全天条或在时间轴长按；网格布局可把「+」拖到某天。
- **未排期任务**（✅）：日历右上「…」→ **Arrange tasks**（移动端也可从右边缘左滑呼出），面板里是所有无日期任务，拖进日历即排期。
- **点击任务**（⚠）：打开任务详情面板（桌面右侧详情区 / 移动端详情页），可改日期、提醒、清单、标签、附件、进度 — 详情字段见 https://help.ticktick.com/articles/7055782408586526720
- **日历外观**（✅）：View Options 内可设 颜色（按清单/标签/优先级）、Filter View Range（按清单过滤日历内容）、Style（Modern/Classic）、Show Item Icons、附加时区（最多 5 个）、Show Details / Show Check Items / Show All Repeat Cycles / Show Habit / Show Focus Records — https://help.ticktick.com/articles/7055782085826445312 （2026-09-11）
- **日历内批量**（✅）：Ctrl/Cmd 点选或框选多个任务，拖动改期或右键批量操作，Postpone 批量顺延；**仅 Windows 与 Web，macOS 尚不支持拖拽** — 同上

### 1.3 列表 ↔ 日历

- 右上角**视图切换器**；桌面快捷键 Y / 4 直接进年视图（✅，Year View 文档）
- **Split View**（✅，桌面/Web）：右键任务图标 → "Show with Calendar"，日历出现在列表右侧；或右键日历图标 → "Show with Task"。列表里的任务可直接拖进日历排期，也可把任务拖到清单/标签/智能清单上（自动打标签或套用时间条件）— https://help.ticktick.com/articles/7358389904469917696 （2026-09-11）
- 列表的筛选（Filters/智能清单）与日历的 Filter View Range **是两套独立设置**（✅，分别见两篇文档），切换时并不共享筛选条件（⚠：文档未明说，但设置项位置不同）。

### 1.4 移动 vs Web/桌面

- 移动端：周视图有**时间轴布局与 8 宫格布局**两种（网格布局里可把「+」拖到某个日期格建任务）；月视图**双指缩放**可变成多周日历（Multi-week）；日视图 / 3 日视图为移动端独占。
- 桌面独占：议程、多日/多周视图、Split View、批量框选、快捷键；**迷你日历仅 Web+Windows**（FAQ 原文："This feature is exclusive to the Web & Windows version"）；日历内批量拖拽也仅 Windows+Web。
- 默认「各设备的视图设置相互独立」；可开 **Sync View Across Devices** 统一，但该开关**仅 Android 与 Web**（原文："> Available on Android and Web only."）— https://help.ticktick.com/articles/7055782365863346176

## 2. Todoist

### 2.1 列表视图

- **默认排序**（✅）：Today / Upcoming / 带日期的过滤器视图按「日期时间（无日期则用 deadline）→ 优先级 → deadline → 手动顺序 → 创建时间」智能排序；项目内按添加顺序、且**只在版块内排序**（"tasks are sorted within each section, rather than across sections"）— https://www.todoist.com/help/todoist/features/default-sorting-order-in-todoist-mqmgerY7 （更新日期未取到）
- **分组**（✅）：可按 **日期 / 添加日期 / 截止期限 / 优先级 / 标签** 分组；一旦分组就不能手动拖拽排序 — https://www.todoist.com/help/todoist/features/sort-or-group-tasks-in-todoist-WFWD0hrb （2026-09-17）
- **Upcoming 是按日期组织的**（✅）：词汇表定义 "Upcoming view displays your tasks organized by date over the coming days and weeks"；正文 "See every task scheduled for the next 7 days (and beyond)"，顶部有周选择器（week picker），可向后看两年 — https://www.todoist.com/help/todoist/get-started/plan-your-week-with-the-upcoming-view-OKOg1mR8 （2026-10-23）、https://www.todoist.com/help/todoist/get-started/todoist-glossary-cA60laWMH （2026-10-12）
- **只显示有日期任务**（✅）："Only tasks with a date appear in Today and Upcoming. A task added without a date won't show up in either view." — https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs （2026-10-23）
- **单行信息**（⚠）：圆圈勾选、标题、描述首行、截止/日期、优先级色、标签、子任务/评论图标；官方文档以截图为主，未逐项列。
- **快速操作**（✅/⚠）：
  - 点圆圈完成、可 Uncomplete（Display → Completed tasks 打开后点圆圈恢复）— https://www.todoist.com/help/todoist/features/introduction-to-tasks-080OAXric （2026-09-30）
  - 行右侧「⋯」菜单 → 复制 / 删除（✅）；点击任务打开**任务视图**（右侧详情，含描述、子任务、评论、附件）（✅）
  - 拖拽排序；「把任务拖到 Today 列表底部 = 顺延到明天」（仅未开分组/排序时）— https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs
  - 逾期批量处理：右上角 **Reschedule** 按钮。注意原文限定："**In a filter or label view**, the Reschedule button appears at the top-right of the task list only when tasks are grouped by Date."（过滤器/标签视图里按非日期分组时看不到）— https://www.todoist.com/help/todoist/get-started/plan-your-week-with-the-upcoming-view-OKOg1mR8
- **筛选**（✅）：Display 菜单可 Filter by Assignee / Date / Deadline / Priority / Label / Workspace；分组/排序/筛选默认只改自己的视图，共享项目里可 **Save for everyone** 保存为默认视图 — 同上
- **批量**（✅）：Web/桌面 `Cmd/Ctrl + Shift` 点首尾任务 = 范围多选；移动端 Browse → 项目「⋯」→ Select Tasks（或长按 → Select Task）。选中后**底部多选工具栏**：Date / Move to / Labels / Delete，更多菜单里还有 Priority / Assign to / Deadline / Complete — https://www.todoist.com/help/todoist/features/add-or-manage-multiple-tasks-in-todoist-PcPoskdUp （2026-10-23）

### 2.2 日历视图

- **模式**（✅，官方原文表格）：
  | Layout | 官方描述 |
  |---|---|
  | Day calendar | "Focus on today. Review what's overdue and due today, and time-block your tasks" |
  | Week calendar | "Plan your week… On mobile, you'll see 3 days at a time; on desktop, the full 7-day view" |
  | Month calendar | "Look ahead… next 30 days in a project, filter, label, or the Upcoming view" |
- **可作为布局应用的视图**（✅）：项目、Inbox、Today、Upcoming、Filters & Labels — https://www.todoist.com/help/todoist/features/use-the-calendar-layout-in-todoist-lPHRQTu0o （2026-10-23）
- **全天 vs 定时**（✅）：未排时间的任务在 Plan 侧栏 / 全天区域，拖进时间轴后自动获得时间与时长（"Touch and drag any all-day tasks into the calendar to time-block them"）；全天任务在日历上有 deadline chip（"Add a deadline to view a deadline chip in the calendar"）— https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs
- **已完成**（✅）：日历里默认不显示；"In projects, completed recurring tasks only show in the calendar layout"（循环任务的已完成实例只在日历布局可见），列表里只看得到下一次 — https://www.todoist.com/help/todoist/features/view-completed-tasks-in-todoist-J19h2s （2026-10-23）
- **逾期**（✅）：日历布局下 **Plan 侧栏**集中列出 "overdue, all-day, time-blocked, and unscheduled tasks with a deadline (up to 7 days ahead)"，点或拖即可改期 — https://www.todoist.com/help/todoist/get-started/plan-your-week-with-the-upcoming-view-OKOg1mR8
- **拖拽**（✅）：拖任务到另一天改日期；拖到某小时 = 建立时间块；"Expand or shorten the task to add a duration"（拖块边缘改时长）；移动端可先按住空白时段再拖任务块决定时间。
- **空白新建**（✅）："Click the day to schedule a task in the calendar."（Web/桌面）；移动端 "Press and hold an empty calendar slot to add a task. Before you add it, you can drag the task block to another time or visible day." — 均见日历布局文档
- **未排期任务**（✅）：项目右上 **No date** 按钮 → 展开侧栏列出无日期任务 → 拖到日历即赋值日期（也可用「⋯」里的 scheduler 选日期）。
- **点击任务**（⚠）：打开任务视图（右侧详情），不是模态弹窗。
- **颜色**（✅）：默认按优先级着色，可改为按标签或项目；周/3日/月布局均生效 — 日历布局文档
- **限制**（✅）："Manual sorting isn't available for the calendar layout."；想排序/分组必须切回 List/Board。

### 2.3 列表 ↔ 日历

- 右上 **Display → Layout**（List / Board / Calendar），同一视图内切换；**布局是每个视图自己的属性**（项目/过滤器/标签/Inbox/Today/Upcoming 各存一份）✅；但「切换布局后筛选条件是否原样保留」文档没明说（⚠，按视图模型推断应保留）；日历布局下分组/排序不可用（✅）
- 顶部有 **Plan** 按钮（仅日历布局）打开 Plan 侧栏（✅）
- Today/Upcoming 的周选择器在 list/board/calendar 三种布局下都在（✅）

### 2.4 移动 vs Web

- 移动端日历没有 Month 布局：**iOS = Agenda 或 Week（竖屏 3 天、横屏 7 天）**，**Android = Agenda 或 3-day**；Web/桌面 = Week / 3 days / Month（✅，日历布局文档的分平台步骤）
- "Future occurrences"（让循环任务显示全部未来实例）在 Web/桌面/iOS 可用，原文特别注明 Today 视图里也生效的是这三端（✅，同上）
- Android 小组件 / Wear OS 的 Upcoming 只显示未来 7 天、没有 week picker（✅）— https://www.todoist.com/help/todoist/get-started/plan-your-week-with-the-upcoming-view-OKOg1mR8
- 移动端拖「Dynamic Add」按钮到某天来建任务（✅）；桌面有全局快捷键 Quick Add（✅）

## 3. Microsoft To Do / Outlook 任务

## 5. Things 3（Cultured Code）

> 注意：Things 只有 Mac / iPad / iPhone / Vision，**没有 Web 版、没有 Windows**；也**没有日历网格视图** —— 这两点本身就是设计取舍的参考。

- **四个日期清单 + Logbook**（✅）：
  - **Today**：start date / deadline / 重复规则命中今天的任务；日历事件显示在列表顶部（"Enable calendar integration to also see today's calendar events at the top"）；可把任务丢进 **This Evening** 分区（列表底部的独立段落）；长列表可改为「按项目/领域分组」（设置项）

  - **Someday**：未计划的；与 Anytime/Upcoming 互斥
  - **Logbook**：完成/取消的归档（✅）
  - 另有隐藏清单 **Tomorrow** 与 **Deadlines**（按截止日排序），通过 Quick Find 进入（✅）
  — https://culturedcode.com/things/support/articles/4001304/ 、https://culturedcode.com/things/support/articles/2803579/
- **核心概念区分**（✅）：start date 只表示「哪天开始做」，deadline 表示「最晚哪天完成」；两者分离。"Unlike a calendar, where you schedule your appointments for durations, a start date in Things merely indicates the day on which you want to begin work on a to-do." — 同上
- **单行信息**（⚠）：勾选圆、标题、标签、日期/截止、备注图标、清单/项目名；行内展开（点任务）出现 When 日期选择器、备注、清单项。

## 9. 给本项目的「列表 + 日历」设计建议（10 条）

> 我们的字段比这些产品多了「地点/来源/附件」，少了「项目/优先级」。建议把「来源」当颜色维度，「状态」当 Tab，把「地点」做成行内次要信息 + 日历块上的小图标。

1. **顶部固定「列表 / 日历」分段控件，切换不丢筛选**（借鉴 Todoist 的 Display→Layout、Notion 的视图 Tab）。
   把「状态 Tab（未完成/已完成/已归档）+ 关键词 + 来源 + 日期范围」放在视图之上、两种视图共用；不要像 TickTick 那样列表与日历各有一套筛选（TickTick 的 Filter View Range 与 Filters 就是两套，用户要学两次）。

2. **列表按日期分组，档位就用 Time 五档 + 无日期**：逾期 / 今天 / 明天 / 未来 7 天 / 以后 / 无日期（借鉴 TickTick "Group by Time"、Things Upcoming「明天起 7 天」、MS To Do Planned）。
   「无日期」单独成组放在最末（Todoist 排序时把无日期放底部，这是同类产品的默认心理预期）。

3. **给「无日期」一个固定停靠区，而不是催用户填日期**：列表右侧常驻可折叠「未排期」抽屉，拖到日历即落日期（借鉴 Todoist 的 **No date** 侧栏 + TickTick 的 **Arrange tasks**）。
   这是「列表 → 日历」最高频的动作，建议做成首屏可见，而不是藏在「⋯」里。

4. **日历采用「全天条 + 时间轴」两段式**：有 `time` 的进时间轴，无 `time` 的进顶部全天条（借鉴 TickTick Week View 原文定义、Google 日历 Deadline 落在 All day 区）。
   全天条高度可拖拽调整；同一天全天任务超过 2 条时折叠为「+N」（折叠阈值是我们的设计决定：本次没有找到任何一家官方文档写明溢出规则，见第 8 节）。

5. **日历模式按性价比排优先级：议程 → 周 → 月 → 日**。
   议程（按时间线性罗列，含过去已完成）实现成本最低、对「个人日常助手」价值最高（借鉴 TickTick Agenda 与 Todoist 移动端 Agenda）；周视图做 7 列时间轴（Todoist 桌面端全 7 天、移动端 3 天）；月视图先不做多日/年（TickTick 的多日/多周/年视图是增值项，不是刚需）。

6. **点空白即建、点任务开右侧详情抽屉**：空白格点击 → 预填该日期（有时间轴则预填时间、默认 1 小时）；点任务 → 右侧抽屉，保留日历上下文，抽屉里改日期/时间/地点/附件/状态（借鉴 Notion 的 Side peek、Todoist Task view、TickTick 详情区）。
   不要用居中模态弹窗——日历场景里用户需要一边看格子一边改。

7. **三种拖拽一次做全**：拖块改日期、拖块改时间、拖块上下边缘改时长（借鉴 TickTick「边缘出现上下箭头后拖动」、Todoist "Expand or shorten the task"、Notion 拖边缘拉成多天）。
   拖拽时给出目标时间提示（如「周四 14:00–15:00」），松手即保存并 toast + 撤销。

8. **已完成 = 留在原位变淡 + 删除线，另给「显示已完成」开关**（借鉴 TickTick 的 Show Completed + 颜色变淡；删除线是我们的补充，因为归档态需要一眼可辨）。
   日历默认不显示已完成；勾选完成的瞬间不要让它消失（否则用户会怀疑没保存），而是变淡并在 1.5s 后按设置隐藏。

9. **逾期用「颜色 + 分组」双信号，不做单独页面**：列表里逾期组标题用警示色、日期文字标红；日历里逾期块左侧加红色竖条；月视图顶部提供「N 个逾期」快捷入口跳到列表逾期组（借鉴 TickTick 的 Overdue 分组、Todoist 的 Reschedule 批量按钮、Google 的 Pending tasks 入口）。

10. **状态用 Tab，来源用颜色，地点用图标**：
    - 状态 Tab（未完成/已完成/已归档）沿用现有原型，但**日历视图里状态改为过滤开关**（借鉴 Google「Show completed tasks」）；
    - 颜色编码只用一个维度，建议按「来源」（借鉴 Todoist 的 Coloring: Priority/Label/Project、TickTick 的 Color by List/Tag/Priority），并在图例里可切换成按状态着色；
    - 地点在列表行尾显示 📍+短名，在日历块上只在高度足够时显示（避免块内文字溢出）。
